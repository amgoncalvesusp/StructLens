# StructLens v0.3.0

## Highlights

- Multiple Sequence Alignment with bundled MUSCLE 5.3.
- Alignment conservation, gap/ambiguity profiles, and sequence logo data.
- Structural interaction gain/loss analysis with reference normalization.
- Active-site comparison with global-frame/site-fitted RMSD, SASA, and atomic envelope volume.
- Distance-difference maps and structural displacement vectors.
- Residue Evidence Card with categorical evidence quality.
- Updated StructLens-PyMOL bundle and visualization plugin.
- Click-to-install Windows setup, Linux Debian package, and portable AppImage.

## Limitations

StructLens is descriptive. It does not predict function, pathogenicity,
antimicrobial resistance, stability, binding affinity, or damage. Interaction
analysis uses static structures; heavy-atom H-bonds may be putative. Atomic
envelope volume is not cavity volume, and MSA conservation is not
phylogenetically weighted.
