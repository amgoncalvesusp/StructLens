# StructLens v0.3.0

StructLens v0.3 is a descriptive protein sequence and structure analysis
platform. StructLens is the scientific source of truth; StructLens-PyMOL only
visualizes stored results.

## Multiple Sequence Alignment

MUSCLE 5.3 is bundled in release builds. Rows use generated IDs and are
reconnected to `AnalysisSequence` source residues after parsing. Alignment
columns are not PDB residue numbers. Reference-gap columns remain explicit and
target insertions use reference-relative labels such as `A:166+1`.

## Alignment Conservation and Sequence Logo

Canonical amino acids are counted after gaps and ambiguous `X/B/Z/J` symbols
are separated. Shannon entropy is reported in bits and normalized alignment
conservation is `1 - H/log2(20)`. Sequence-logo letter heights are
`p_i × (log2(20) - H)`. This is alignment conservation, not phylogenetically
weighted evolutionary constraint.

## Structural Neighborhoods and Interaction Differences

Neighborhoods use reference-selected heavy atoms and map targets through the
authoritative correspondence. Thresholds and chemistry tables are centralized.
Heavy-atom geometry without explicit hydrogens is labelled a putative H-bond.
Interaction differences are conserved, gained, lost, or target-only-unmapped;
target residue numbers are never compared directly.

## Active-Site Comparison

Sites can be defined by key residues, ligand radius, or residue radius. Site
coverage is mapped residues divided by reference site residues. Both global-frame
and site-fitted backbone RMSD are retained. The convex-hull metric is named
**site atomic envelope volume (Å³)**; it is not cavity or pocket volume. SASA
is supplied by FreeSASA in release builds and is unavailable, never zero, when
the backend cannot calculate it.

## Distance-Difference Maps

For mapped Cα positions, `Δd = target internal distance - reference internal
distance`. The matrix is rigid-body invariant and does not require superposition.
Positive values mean farther apart; negative values mean closer. Missing pairs
are masked explicitly.

## Structural Displacement Vectors

Vectors start at reference Cα coordinates and end at target Cα coordinates after
exactly one target-to-reference transform. The stored magnitude is validated
against the vector norm. The default display threshold is 0.5 Å and the default
display limit is 100 vectors.

## Residue Evidence Cards

An Evidence Card aggregates sequence, structure, interaction, site, and
categorical quality evidence. It is not an impact, pathogenicity, stability,
binding-affinity, or functional score. Missing target evidence is marked
unavailable or partial.

## Scientific limitations

- No functional, pathogenic, resistance, stability, or affinity prediction.
- Interaction analysis is static-structure and geometry based.
- Heavy-atom H-bonds may be putative.
- Site atomic envelope volume is not cavity volume.
- MSA conservation is not phylogenetically weighted.

## Reproducibility and exports

Project schema `3.0` records MSA settings, thresholds, sites, distance-map
metadata, backend versions, and Evidence Card provenance. XLSX sheets retain
numeric values and blank unavailable cells. JPEG and TIFF publication exports
support 300 and 600 DPI from source render dimensions; screenshots are not
resized and relabelled.

## Installation

Windows release: double-click `StructLens-v0.3.0-Windows-x86_64-Setup.exe`.
Linux Debian: install `structlens_0.3.0_amd64.deb`. Portable Linux: run
`StructLens-v0.3.0-Linux-x86_64.AppImage`. All releases bundle Python, Qt,
US-align, MUSCLE, and FreeSASA resources and include SHA-256 checksums.

## PyMOL Plugin

Install `StructLens-PyMOL-v0.3.0.zip` with PyMOL Plugin Manager. The plugin
loads v0.3 bundle sections for evidence, interactions, sites, and vectors. It
does not recalculate mapping, RMSD, transforms, or metrics.
