# Scientific methods

## Mapping

Sequence mode uses Biopython's global PairwiseAligner with an explicit BLOSUM62 matrix and serialized gap-open/gap-extend settings. AUTO reports the identity and reference coverage used to choose sequence-guided mapping; below the configured thresholds it requires the US-align structural adapter. Manual mappings are explicit and may be marked locked.

## Geometry

Kabsch fits target row-vector coordinates onto reference coordinates and explicitly corrects reflections. Strict Cα RMSD uses all eligible mapped Cα pairs. Refinement iterates a configured Å cutoff and retains excluded correspondences with `is_outlier=True`. A one-pair Cα value is displayed as Cα displacement, never RMSD.

Per-residue backbone RMSD requires N, Cα, C, and O in both residues. Side-chain and all-heavy-atom RMSDs require complete matching heavy-atom name sets; valid ASP/GLU/ARG/PHE/TYR symmetry permutations are evaluated and the minimum chemically valid RMSD is used. Missing atoms produce an unavailable metric.

## Mutation descriptors

Mutation classification happens after mapping and distinguishes conserved, substitution, insertion, deletion, and non-standard residues. BLOSUM62 and Grantham are embedded, test-verified descriptors. Physicochemical categories are descriptive and carry no functional claim.

## Interfaces between protein or peptide chains

Choose a coordinate model and two distinct chains from one structure. A residue pair is in contact when its minimum distance between eligible heavy atoms is at or below the chosen cutoff (default 5.0 Å). Each residue pair appears once even if several atoms are close. A residue’s partner count is the number of distinct contacting residues on the other chain. The closest atom pair establishes the minimum distance. Additional chemistry annotations describe geometries within the contacting pairs.

The calculation uses the coordinates supplied. To assess a quaternary assembly generated by symmetry, first load a coordinate file containing the assembled chains as distinct instances. Crystal contacts can differ from the biological interface. [PDB guide to biological assemblies](https://pdb101.rcsb.org/learn/guide-to-understanding-pdb-data/biological-assemblies)

Within the selected cutoff, the module flags candidate hydrogen bonds at up to 3.5 Å between eligible donor and acceptor atoms, salt bridges at up to 4.0 Å between specified Asp/Glu and Lys/Arg side-chain groups, and hydrophobic contacts at up to 4.5 Å between eligible nonpolar side-chain atoms. The hydrogen-bond annotation uses heavy-atom geometry without an explicit hydrogen or angle requirement. The contact list cannot assess residues entirely missing from the coordinates.

Many neighbors can make a residue a useful candidate for mutagenesis. The number of contacts does not quantify its contribution to binding free energy. Testing that contribution requires additional evidence, such as an affinity change after substitution. [Bogan and Thorn, 1998](https://pubmed.ncbi.nlm.nih.gov/9653027/)

## Reproducibility

Project JSON stores schema version, source paths, mapping settings, key residues, visualization state, correspondence tables, mutation descriptors, exclusions, and provenance. Source numbering preserves author sequence IDs, insertion codes, and mmCIF label sequence IDs.
